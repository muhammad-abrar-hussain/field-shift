How we know

Every number in this tool comes from measured data. Here is how well it held up when we tested it.

0.118average error on years the model never saw (NDVI), vs 0.129 for a fair baseline without weather
80%of real values fall inside the range we show (p10 to p90)
r = 0.86NASA greenness vs USDA wheat yield, 6 published years: a sanity check, not proof
1,490clean wheat field years from 1,000 sample fields, 2013 to 2025

How the number is built

Crop health = year effect (season rain and heat days, NASA POWER) + rotation effect (how each rotation's wheat compared with the county average in the same year, NASA MODIS NDVI on USDA crop maps). Effects from few fields are shrunk toward zero, and a rotation with few examples is never shown as the best match. We also tested a LightGBM model; it did not beat this simpler one, so we did not ship it.
